Core behavior
-------------
1. Fast semantic evidence planning can run for ordinary multi-word natural-language queries.
2. Planner-generated terminology is SEARCH-ONLY and cannot become answer evidence.
3. Evidence goals carry explicit coverage contracts.
4. Configured/selected priority sources are searched in a separate first stage.
5. Precise lexical search remains; a separate relaxed recall lane is added.
6. Existing section_path/search_vector fields provide bounded section navigation.
7. Table-specific boost is gated by request structure instead of being applied to every query.
8. Required goals receive bounded goal-local cross-encoder reranking before fan-in.
9. An evidence-quality audit gates broadening.
10. Incomplete priority retrieval gets one materially different AI query-repair pass first.
11. Repair probes are scheduled before failed seed queries in targeted recovery.
12. Auto broadens only unresolved goals after priority-source recovery remains incomplete.
13. Retrieval trace includes source-policy, priority-stage, goal-local and repair observability.
14. Definition/variant/list/procedure coverage is not declared complete from candidate presence alone.
